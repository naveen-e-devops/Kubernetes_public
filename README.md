# Production-Grade Kubernetes & EKS Learning

A hands-on learning program to go from Kubernetes fundamentals to operating a production-oriented AWS EKS platform.

## Technology Stack

- Kubernetes
- AWS EKS
- Terraform
- Argo CD
- Karpenter
- Prometheus
- Grafana
- AWS ECR
- GitHub / GitLab CI/CD

## Learning Path

1. Foundations
2. Kubernetes Fundamentals
3. Kubernetes Workloads
4. Kubernetes Networking
5. AWS & EKS Foundations
6. Terraform EKS
7. Production EKS
8. Argo CD / GitOps
9. Karpenter
10. Prometheus & Grafana
11. Kubernetes Security
12. Production Operations
13. Production EKS Capstone

## How We Learn

Each topic follows:

**Learn → Build → Break → Troubleshoot → Automate → Document → Assignment**

See [docs/architecture.md](docs/architecture.md) for the target production architecture.

## Target Outcome

By completing this repository, you will build and operate a production-oriented EKS platform where:

- Terraform provisions AWS infrastructure.
- Argo CD manages Kubernetes application state.
- Karpenter manages dynamic workload capacity.
- Prometheus collects metrics.
- Grafana provides dashboards and alerts.
- Kubernetes RBAC and NetworkPolicies provide workload access controls.
- Multi-AZ design and resilience practices are applied.
- CI/CD validates infrastructure and application changes.
- Production failures, upgrades, backup, and disaster recovery are practiced.

## Course Workspace

As each phase is completed, implementation code, assignments, troubleshooting notes, and production considerations will be added to this repository.

# Learning Method

This repository is a hands-on course rather than a collection of notes.

For every phase:

## 1. Learn

Understand the architecture and terminology.

## 2. Build

Implement the smallest working example.

## 3. Break

Intentionally introduce a failure.

## 4. Troubleshoot

Use kubectl, AWS CLI, logs, events, Prometheus, Grafana, and platform tooling to identify the root cause.

## 5. Automate

Replace manual steps with Terraform, GitOps, or CI/CD where appropriate.

## 6. Document

Record architecture decisions, commands, troubleshooting steps, and production considerations.

## 7. Complete the assignment

Do not move to the next phase until the assignment is complete.

## Production Mindset

For every component ask:

- What happens when it fails?
- How does it scale?
- How is it secured?
- How is it monitored?
- How is it upgraded?
- How is it recovered?
- What is the blast radius?
- Can the configuration be reproduced?
- Can another engineer operate it?
